# Workout Tracker

Personal app to log workouts, track weekly workouts, and view your workout history.

> 🚧 Project in development — still under construction, see [PLANNING.md](./PLANNING.md) for design details.

## Key Features

- Daily Workout View with Planned Exercises
- Real-time Recording of Sets (Reps, Load)
- Past Workout History

## Technology Stack

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: Python (Flask)
- **Database**: To be defined (see roadmap)
